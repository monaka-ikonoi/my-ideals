# My Ideals - 记录你的生写真收藏

[English](./README.en.md) | [日本語](./README.ja.md) | [中文](./README.zh.md)

My Ideals 是一个用于管理偶像生写真收藏的 Web 应用。

- ✅ 标记已持有的照片，或以**复数模式**记录持有数量
- � 在复数模式下用**负值**标记**求收**项目
- 📊 一览收藏进度（按合集、按成员）
- 🔍 快速搜索、按成员与状态筛选、隐藏已完成合集
- 🖼️ 将收藏结果**导出为图片**，方便分享
- 🔄 模板更新时自动检测并提示
- 💾 数据保存在浏览器中 - 无需注册账号

## 快速上手

### ⚠️ 警告

本应用所有数据仅保存在浏览器本地（IndexedDB / localStorage），清空浏览器数据、使用无痕模式或更换设备都将导致数据永久丢失，请务必定期导出备份数据。**开发者不对因数据丢失造成的任何损失负责，也无法协助恢复已丢失的数据。**

> iOS / iPadOS / Safari 用户请特别注意：受 Apple ITP 限制，连续 7 天未访问可能导致本地数据被自动清除。每次使用后请及时导出备份。

### 创建档案

1. 从以下菜单中选择 **“新建档案”**。
   - **电脑端**：点击右上角的下拉列表
   - **手机端**：点击右上角的三横线（汉堡菜单）
2. 粘贴模板 URL（从 [此处](https://github.com/monaka-ikonoi/my-ideals/issues/1) 或模板制作者处获取）
3. 输入档案名称
4. 如需记录**持有数量**，勾选 **“复数记录模式”**（也可日后在档案菜单中切换）
5. 点击 **“创建”**

### 筛选与搜索

- 使用搜索框按合集名称快速查找
- 点击**成员筛选**按钮只显示特定成员（适用于包含多个成员的模板）
- 通过**状态筛选**仅查看“全部 / 已持有 / 未持有 / 求收”
- 开启 **“隐藏已完成的合集”** 专注于尚未完成的部分

### 记录收藏

1. 浏览各个合集
2. 点击任意条目标记为 **已持有** ✓
3. 在**复数模式**下，可记录每个条目的持有数量；输入**负值**即标记为 **求收** 💗（标准模式无此功能）
4. 进度自动保存

### 管理档案

- 可创建**多个档案**（例如：按团体、按用途分类）
- 在档案菜单中可进行**重命名**、**创建副本**、**重新排序**、**删除**
- 当模板作者发布更新时，应用会提示**模板差异**（新增 / 移除的条目），并让你选择保留或清理已移除的数据
- 如果模板 URL 失效，使用 **“编辑模板链接”** 更新

### 备份与分享

- 点击右上角的 **“导出”** 下载档案数据文件（JSON），可在另一设备上导入恢复
- 使用 **“生成图片”** 将所选合集导出为一张图片，便于在社交平台分享

## 工作原理

**模板 (Template)** = 社区创建的照片列表

模板定义了一个系列有哪些照片（例如：“2024 夏季演唱会周边”）。模板作者会维护这些列表，你不需要手动输入每个条目。只需粘贴模板链接即可开始使用。

> 📝 想制作自己的模板？请参阅 [Template JSON 说明文档](./docs/zh/template.md)。

**档案 (Profile)** = 你的个人收藏记录

档案基于模板，记录你拥有哪些照片（以及在复数模式下持有的数量）。你可以创建多个档案。

```
模板（共享）         档案（个人）
┌─────────┐       ┌─────────┐
│ A       │       │ A    ✓  │  ← 已持有
│ B       │  -->  │ B   ×2  │  ← 复数模式：持有 2 个
│ C       │       │ C   -1💗│  ← 复数模式：负值 = 求收
│ ...     │       │ ...     │
└─────────┘       └─────────┘
```

## 常见问题

**Q：数据保存在哪里？**

A：所有数据保存在浏览器本地（IndexedDB，旧环境回退到 localStorage），不会发送到任何服务器。

**Q：如果清除浏览器数据会怎样？**

A：收藏数据会丢失。清除前请务必导出备份。iOS / Safari 用户即使不主动清除，连续 7 天未访问也可能因 ITP 而丢失数据。

**Q：可以在多个设备上使用吗？**

A：可以，但数据不会自动同步。请从一台设备导出，然后在另一台设备导入。

**Q：标准模式和复数模式有什么区别？**

A：标准模式仅记录“有 / 无”；复数模式可记录每个条目的持有数量。可以在档案菜单中随时切换，但从复数切换回标准时，持有 2 个以上的数据将被压缩为 1。

**Q：什么是模板？**

A：模板是定义照片列表的 JSON 文件。模板作者维护这些列表，用户无需手动输入每个条目。模板更新后，应用会自动检测并向你展示差异。

**Q：模板链接失效了怎么办？**

A：在档案菜单中点击 **“编辑模板链接”** 更新链接。如果模板已迁移，请向模板作者获取新链接。

**Q：如何把收藏发到社交平台？**

A：使用合集页面的 **“生成图片”** 功能，将所选合集导出为一张图片即可分享。
