# My Ideals - 生写真コレクション記録アプリ

[English](./README.en.md) | [日本語](./README.ja.md) | [中文](./README.zh.md)

My Ideals は、アイドルの生写真コレクションを管理するための Web アプリです。

- ✅ 持っている写真をチェック、または**複数モード**で所持数を記録
- 💗 複数モードで**負の値**を入力して**求**アイテムをマーク
- 📊 コレクション進捗を一目で確認（コレクション別・メンバー別）
- 🔍 素早く検索、メンバー・状態でフィルター、完了済みコレクションの非表示
- 🖼️ 選択したコレクションを**画像として出力**して共有
- 🔄 テンプレート更新を自動検知
- 💾 データはブラウザに保存 - アカウント不要

## クイックスタート

### ⚠️ 注意

本アプリのすべてのデータはブラウザのローカル（IndexedDB / localStorage）にのみ保存されます。ブラウザデータの消去、シークレットモードの使用、デバイスの変更により、データは永久に失われます。定期的にバックアップをエクスポートしてください。**開発者はデータ損失による損害について責任を負わず、失われたデータの復旧もできません。**

> iOS / iPadOS / Safari をお使いの方は特にご注意ください。Apple ITP の制限により、7 日間アクセスがないとローカルデータが自動的に消去されることがあります。利用後は毎回バックアップをエクスポートしてください。

### プロファイルを作成

1. 以下のメニューから **「新規プロファイル」** を選択します。
   - **PC の場合**：右上のドロップダウンリストをクリック
   - **スマホの場合**：右上の三本線（ハンバーガーメニュー）をクリック
2. テンプレート URL を貼り付け（[こちら](https://github.com/monaka-ikonoi/my-ideals/issues/1) やテンプレート作成者から取得）
3. プロファイル名を入力
4. **所持数**を記録したい場合は **「複数記録モード」** を有効化（後からプロファイルメニューで切り替え可能）
5. **「作成」** をクリック

### 検索とフィルター

- 検索ボックスでコレクション名から素早く探す
- **メンバーフィルター**ボタンで特定のメンバーのみ表示（複数メンバーを含むテンプレートで便利）
- **状態フィルター**で「すべて / 所持 / 未所持 / 求」を切り替え
- **「完了済みコレクションを非表示」** で未完了に集中

### コレクションを記録

1. コレクションを閲覧
2. アイテムをクリックして **所持** ✓ をマーク
3. **複数モード**では各アイテムの所持数を記録できます。**負の値**を入力すると **求** 💗 としてマーク（標準モードにはこの機能はありません）
4. 進捗は自動保存されます

### プロファイルの管理

- **複数のプロファイル**を作成可能（例：グループ別、交換用など）
- プロファイルメニューから **名前変更**・**複製**・**並べ替え**・**削除** が行えます
- テンプレート作者が更新を公開すると、**テンプレート差分**（追加 / 削除されたアイテム）が表示され、削除されたデータを残すか整理するか選べます
- テンプレート URL が無効になった場合は **「テンプレート URL を編集」** で更新

### バックアップと共有

- 右上の **「エクスポート」** をクリックしてプロファイルデータ（JSON）をダウンロード。別のデバイスでインポートして復元できます
- **「画像を生成」** で選択したコレクションを 1 枚の画像として出力。SNS での共有に便利です

## 仕組み

**テンプレート (Template)** = コミュニティが作成した写真リスト

テンプレートは、セットにどんな写真があるかを定義します（例：「2024 年夏コンサートグッズ」）。テンプレート作成者がリストをメンテナンスするので、自分で一つ一つ入力する必要はありません。テンプレート URL を貼り付けるだけで始められます。
> 📝 自分でテンプレートを作りたい方は [Template JSON ガイド](./docs/ja/template.md) をご覧ください。
**プロファイル (Profile)** = あなた個人のコレクション記録

プロファイルはテンプレートを使って、どのアイテムを持っているか（複数モードでは所持数も）を記録します。複数のプロファイルを持つことができます。

```
テンプレート（共有）     プロファイル（自分用）
┌─────────┐            ┌─────────┐
│ A       │            │ A    ✓  │  ← 所持
│ B       │    -->     │ B   ×2  │  ← 複数モード：2 枚所持
│ C       │            │ C   -1💗│  ← 複数モード：負値 = 求
│ ...     │            │ ...     │
└─────────┘            └─────────┘
```

## よくある質問

**Q: データはどこに保存されますか？**

A: すべてのデータはブラウザのローカル（IndexedDB、古い環境では localStorage にフォールバック）に保存されます。サーバーには送信されません。

**Q: ブラウザデータを消去したら？**

A: コレクションデータは失われます。消去前に必ずバックアップをエクスポートしてください。iOS / Safari では手動で消去しなくても、ITP により 7 日間アクセスがないとデータが失われることがあります。

**Q: 複数のデバイスで使えますか？**

A: はい。ただし自動同期はありません。一方のデバイスからエクスポートして、もう一方でインポートしてください。

**Q: 標準モードと複数モードの違いは？**

A: 標準モードは「所持 / 未所持」のみを記録します。複数モードでは各アイテムの所持数を記録できます。プロファイルメニューからいつでも切り替えできますが、複数から標準に戻すと、2 以上の数量は 1 にまとめられます。

**Q: テンプレートとは何ですか？**

A: テンプレートは写真リストを定義する JSON ファイルです。テンプレート作成者がリストをメンテナンスするので、ユーザーは手動で入力する必要がありません。テンプレートが更新されると、アプリが自動的に検知して差分を表示します。

**Q: テンプレート URL が動作しません**

A: プロファイルメニューから **「テンプレート URL を編集」** をクリックしてリンクを更新してください。テンプレートが移動した場合は、作成者から新しい URL を取得してください。

**Q: SNS でコレクションを共有するには？**

A: コレクションページの **「画像を生成」** 機能で、選択したコレクションを 1 枚の画像として出力できます。
